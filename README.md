# Анализ данных авиаперевозок
Исследование данных об авиаперевозках, направленное на изучение структуры и особенностей авиарейсов. В ходе работы была выполнена предварительная обработка и очистка данных, изучены основные характеристики рейсов, распределение показателей и взаимосвязи между ними. По результатам анализа выявлены закономерности, которые представлены с помощью графиков и визуализаций.

Технологический стек:

Pandas

NumPy

Matplotlib

Seaborn
